SurfHost OPNsense plugins

Package repository for OPNsense plugins published by SurfHost. Add it on your firewall once, then install the plugins from System > Firmware > Plugins as usual.

fetch -o /usr/local/etc/pkg/repos/surfhost.conf \
    https://surfhost.github.io/opnsense-repo/surfhost.conf
pkg update

Plugins for FreeBSD:15:amd64

  • os-openvpn-auth-oauth2 1.7.1: OpenVPN SSO via OpenID Connect (Microsoft Entra ID and others) (source and documentation)
  • os-speedtest-surfhost 1.2.1: Internet speed test with history, schedule and dashboard widget (source and documentation)

Dependencies mirrored from FreeBSD because OPNsense does not build them: openvpn-auth-oauth2-1.28.0_4

Served from the gh-pages branch of SurfHost/opnsense-repo.
